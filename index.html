Padel Matchtreff

hAI.MatchtreffPadel

Web-App für den wöchentlichen Padel-Matchtreff am Donnerstag: Spieler tragen sich ohne Registrierung nur mit ihrem Namen in feste Zeit-Slots ein, der Admin steuert die maximale Anzahl pro Slot.

Erklärvideo

Projektüberblick

  • Flask-Web-App ohne Login für Spieler – nur Name eintragen, fertig
  • Zwei feste Donnerstag-Slots: 18:00 - 20:00 und 20:00 - 22:00
  • Admin legt maximale Teilnehmerzahl pro Slot fest
  • Änderungen und Löschungen von Anmeldungen ausschließlich durch den Admin
  • SQLite-Backend im instance/-Ordner
  • Telegram-Bot zum Eintragen & als Admin-Steuerung
  • Docker-/Compose-Setup mit drei Containern (Web, Bot & Scheduler) auf Port 1905

Features

Automatischer Reset

Löscht jede Woche alle Anmeldungen komplett (Standard: Freitag 06:00 Uhr). Konfigurierbar im Admin-Dashboard (Wochentag, Uhrzeit, Intervall).

Anmeldesperre

Die Anmeldung ist für normale Nutzer standardmäßig geschlossen und wird erst wieder freigeschaltet, wenn ein Admin sie öffnet – manuell oder per geplanter Auto-Freigabe zu einem festen Datum/Uhrzeit. Admins können sich immer eintragen.

Hinweistext auf der Startseite

Die Startseite zeigt transparent an, ab wann die Liste öffnet: Standard ist der nächste Dienstag um 13:00 Uhr. Hat ein Admin eine Auto-Freigabe hinterlegt, wird stattdessen deren Datum/Uhrzeit angezeigt; ist die Liste geöffnet, steht dort “Die Liste ist gerade geöffnet.”

Digest-Benachrichtigung

Sammelt neue Anmeldungen und schickt alle 60 Minuten (konfigurierbar) eine Zusammenfassung an die Telegram-Admins. Gäste erhalten weiterhin sofort ihre eigene Nachricht.

Backup-Download

Ein Klick im Admin-Dashboard erstellt eine konsistente Kopie der SQLite-Datenbank – auch bei laufendem Schreibzugriff.

Einträge bearbeiten

Admins können Anmeldungen (Bestätigt + Warteliste) bearbeiten: Name, Mitglied/Gast-Status, Slot und Status, inkl. Dubletten- und Kapazitätsprüfung.

Warteliste

Volle Slots führen automatisch eine Warteliste (max. 4 pro Slot). Bei freien Plätzen rückt die nächste Person automatisch nach.

Design-Themes

Der Admin kann zwischen mehreren Farbschemata und Hintergrundbildern wechseln (Standard, Sunset, Court, Night). Bilder aus static/pictures/ koennen als eigenes Hintergrundbild gewaehlt werden – inkl. Vorschau-Galerie.

Orga-Team-Hervorhebung

Die Orga-Mitglieder werden in der Spielerliste automatisch fett mit Stern (★) markiert.

Tech-Stack

  • Backend: Python, Flask, Gunicorn
  • Datenbank: SQLite (WAL-Modus)
  • Bot: python-telegram-bot
  • Scheduler: APScheduler (eigener Container)
  • UI: eigenes responsives CSS im VfB-Kässle-Design

Deployment via Portainer

Methode A – Git-Stack (Build aus dem Repository)

  1. Portainer → Stacks → + Add stack
  2. Build method: Repository
  3. Repository URL: https://github.com/jbkunama1/hAI.MatchtreffPadel
  4. Reference: refs/heads/main, Compose path: docker-compose.yml
  5. Umgebungsvariablen setzen: SECRET_KEY, ADMIN_PASSWORD_*, TELEGRAM_BOT_TOKEN, ADMIN_TELEGRAM_IDS
  6. Optional: GitOps updates (Polling/Webhook) aktivieren, damit neue Commits automatisch deployt werden
  7. Auf Deploy the stack klicken – Web-App läuft danach auf Port 1905, Bot und Scheduler starten automatisch mit

Methode B – Git-Stack mit fertigem GHCR-Image (empfohlen, kein Build)

Das Image ist bereits fertig gebaut und liegt in ghcr.io/jbkunama1/hai.matchtreffpadel:latest. Im Repository gibt es dafür eine eigene Compose-Datei ohne build: – Portainer holt sich diese Datei und startet das fertige Image einfach:

  1. Portainer → Stacks → + Add stack
  2. Build method: Repository wählen
  3. Repository URL: https://github.com/jbkunama1/hAI.MatchtreffPadel
  4. Reference: refs/heads/main, Compose path: ghcr-docker-compose.yml
  5. Umgebungsvariablen setzen: SECRET_KEY, ADMIN_PASSWORD_*, TELEGRAM_BOT_TOKEN, ADMIN_TELEGRAM_IDS
  6. Auf Deploy the stack klicken – Portainer zieht das fertige Image automatisch (kein Build)
  7. Für Updates: Stack → Actions → Pull and redeploy (holt dann auch das neueste Image)

Hinweis: Falls das GHCR-Paket nicht öffentlich ist, in Portainer unter Registries zunächst ghcr.io mit deinem GitHub-Login hinzufügen.

Automatischer Docker-Build (GHCR)

Ein GitHub-Actions-Workflow baut bei jedem Push auf main automatisch ein Docker-Image und pusht es nach ghcr.io/jbkunama1/hai.matchtreffpadel. Der Build lässt sich auch manuell auslösen (Actions → Docker Build and Push to GHCR → Run workflow).

Ausführliche Details dazu stehen in der README im Abschnitt "Deployment via Portainer (Git-basiert)".

Ablauf für Spieler

  1. Startseite öffnen
  2. Namen eingeben
  3. Slot(s) auswählen (18–20 Uhr, 20–22 Uhr oder beide)
  4. Eintragen – fertig, kein Account nötig
